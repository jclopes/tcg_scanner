# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

### Added

- Camera-based card scanning with perspective correction and OCR-based
  collector-number/set identification, supporting Magic: The Gathering,
  Cyberpunk, Flesh and Blood, Flesh and Blood Classic, and Riftbound.
- Exportable list of scanned cards with quantities, tags, and manual entry.
- A detection telemetry panel showing scan-outcome statistics.
- A debug panel showing each detection pipeline step.
- In-app version display (Help → About).
